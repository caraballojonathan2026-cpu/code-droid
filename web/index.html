🤖 code-droid help

Why is this light?

Android Studio + Gradle + emulator can need 8–16 GB of disk and multiple GB of RAM. code-droid uses a ~300 MB direct toolchain (aapt2 → kotlinc → d8 → zipalign → apksigner) and skips the emulator — you test on a real phone. The whole IDE is one HTML file, one CSS file and two small JS files. No frameworks.

First-time setup

bash tools/install.sh   # downloads ~300MB toolchain, once
npm start               # or: node server/server.js

Run the app on your phone

  1. Enable Developer options → USB debugging on the phone, plug it in, then:
    adb install -r projects/hello-droid/build/app-debug.apk
  2. …or download the APK with the ⬇ APK button, copy it to the phone (USB / Drive / chat) and tap it. Allow “install unknown apps” when Android asks.
