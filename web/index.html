🤖 code-droid

Android Studio's little sibling that fits in a browser tab.

  • Ctrl+P — jump to any file instantly
  • Ctrl+Shift+F — search across the whole project
  • Ctrl+B — hide / show the explorer panel
  • Ctrl+S — save (unsaved work is kept in the browser anyway 💾)
  • ▶ Build APK — compile with the direct toolchain (no Gradle!)
  • ⇧ Import / ⇩ Export projects as .zip — take your work anywhere

🤖 code-droid help

Why is this light?

Android Studio + Gradle + emulator can need 8–16 GB of disk and multiple GB of RAM. code-droid uses a ~300 MB direct toolchain (aapt2 → kotlinc → d8 → zipalign → apksigner) and skips the emulator — you test on a real phone. The IDE is 4 small files, no frameworks.

Your work is safe

Every keystroke is backed up to the browser's localStorage. Close the tab, lose power, restart the server — reopen and your unsaved changes come back (a banner lets you save or discard them). ⇩ Export downloads the whole project as a .zip; ⇧ Import brings one back.

First-time setup

bash tools/install.sh   # downloads ~300MB toolchain, once
npm start               # supervisor + server (the ⟳ button works)

Run the app on your phone

  1. Enable Developer options → USB debugging, plug in, then: adb install -r projects/hello-droid/build/app-debug.apk
  2. …or download the APK with ⬇ APK, copy it to the phone, tap it, allow “install unknown apps”.
